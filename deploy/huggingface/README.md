# Jordanian Constitution Assistant

Ask questions about the Jordanian Constitution and get answers grounded in its
articles.

Bring your own OpenAI API key: paste it into the sidebar. It is used only for
your own questions and is never stored.

AI can make mistakes — double-check important answers against the
[official text](https://representatives.jo/Ar/Pages/%D8%A7%D9%84%D8%AF%D8%B3%D8%AA%D9%88%D8%B1).
